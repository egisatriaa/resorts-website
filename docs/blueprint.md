# **App Name**: Sanctuary Bali Retreat

## Core Features:

- Dynamic Branding & Theme Customization: Users (or site configurators) can adjust resort name, poetic tagline, short description, primary theme accent color, and toggle between dark and light modes to tailor the website's look and feel.
- Cinematic WebGL Hero Section: A high-performance WebGL canvas (Three.js/custom shader) loads and displays an interactive WebP image sequence (e.g., from Supabase), synchronizing frame playback with scroll position for an immersive, cinematic hero experience.
- Smooth Parallax Scrolling Integration: Utilize a library like Locomotive Scroll to achieve smooth, inertial parallax effects for layered elements throughout the page, enhancing depth and engagement.
- Resort Variant Navigation & Transitions: A vertical navigation system allows switching between pre-configured resort 'variants,' featuring cinematic fade transitions and updating all relevant content and visuals.
- AI-Assisted Description Tool: A tool to generate compelling and contextually rich resort descriptions (taglines, short descriptions) based on user-inputted keywords (e.g., 'nature,' 'luxury,' 'serenity,' 'Bali').
- Optimized Content Display: Showcase structured content sections including About, Villas & Suites (with interactive cards), Experiences, Testimonials, Location, and a final Call-to-Action, all designed for visual impact and subtle parallax.
- Progressive Loading & Performance: Implement a full-screen loading overlay with progress indicator, progressive image loading, and requestAnimationFrame for smooth WebGL rendering, ensuring high performance across devices.

## Style Guidelines:

- Primary Color (Ocean Blue): #4DABCC. A serene and sophisticated blue, evoking tropical waters and clear skies.
- Background Color (Light Grey-Blue): #F0F4F5. A very light, desaturated shade of the primary blue, providing a soft, airy canvas.
- Accent Color (Warm Sand Gold): #E6BE7A. A muted, elegant gold to complement the primary blue, reminiscent of sun-drenched sand and luxury details, used for highlights and interactive elements.
- Headline font: 'Playfair' (serif), chosen for its high-end, editorial elegance and 'Canela style' aesthetic, ideal for conveying luxury and sophistication.
- Body text font: 'PT Sans' (sans-serif), paired with 'Playfair' for readability in longer text blocks, providing a modern yet warm contrast.
- Utilize full-screen hero section and other content areas with generous, luxurious spacing and layered elements for depth, particularly in parallax sections.
- Implement smooth, cinematic transitions between content sections and resort variants, ensuring no stutter during WebP sequence playback or parallax scrolling, with subtle fade-ins/outs for text.
- Minimalist and elegant icons, monochrome where possible, for navigation and social media to maintain a high-end visual aesthetic.
